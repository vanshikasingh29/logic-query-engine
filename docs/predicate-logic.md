# Predicate Logic Engine


## Motivation

Database queries are logical statements.


Example:



grade > 80



is a predicate:


P(student)


The database evaluates:


P(tuple)




---

# Boolean Logic


Complex conditions are trees.


Example:



grade > 80 AND grade < 95



Representation:


      AND

   /       \

>80        <95
